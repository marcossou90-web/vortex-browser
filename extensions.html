Instalar por URL ou ID

🧩 Instalar extensão da Chrome Web Store
Cole o ID da extensão ou a URL completa da Chrome Web Store. O Vortex abre a página da extensão para instalação assistida.
Exemplo de ID: cjpalhdlnbpafiamejdnhcphjbkeiagm (uBlock Origin)
📁 Carregar extensão descompactada (modo desenvolvedor)
Carregue uma extensão a partir de uma pasta local (formato descompactado com manifest.json).
Ideal para extensões em desenvolvimento ou extensões baixadas manualmente.
🔗 Extensões populares da Chrome Web Store
